跑法：用 Unity Hub 打开 `client/`（Unity 6000.6.0f1），进 Boot 场景 Play。
生成工程资产：菜单 `Super Mario → 一键生成工程（预制体 + 场景）`。

1. **新设施先登记再写代码**：新增模块 / 面板 / 场景 / 事件 / 资源目录 → 在 `conventions.md` 的对应小节登记。
2. **只记本项目特有的东西**，通用规则**不许**抄进来（抄了必然两边漂移）。
3. **与全局 skill 冲突** → **照全局做**，并把冲突的这一行改掉，然后回报主 agent（⛔ 不许"以本项目为准"）。

## 本项目最容易踩的四件事（先看这个，再看分册）

| 坑 | 一句话 | 详见 |
| --- | --- | --- |
| **一个 .cs 里放多个 MonoBehaviour** | 预制体的 `m_Script` 会指向错的 fileID，运行时面板打不开（且编译期不报错） | `constraints.md` #1 |
| **AudioListener 挂在场景相机上** | 切场景就丢 → 每帧刷屏，日志被刷到 74MB | `constraints.md` #2 |
| **轴心 / 坐标约定** | 角色坐标 = **脚底**；瓦片 (X,Y) 占世界 `[X,X+1]×[Y,Y+1]`；精灵是**紧裁剪**的 | `conventions.md` §坐标 |
| **纯单机项目** | **不生成 `server/`**、不调 `CloverNet.Init`、不查服务器环境 | `conventions.md` §边界 |
