## 二、逐轮搜索记录

### 第 1 轮（英文，关卡数据格式）
- 关键词：`Super Mario Bros NES level data format object data 1-1 hidden 1-UP block coordinates ROM`
- 站点：GitHub（MushROMs/doc/SMB1 Level Format.md、rafaelcp/smbdataset）、nesdev 论坛、TCRF/Data Crystal、6502disassembly.com
- 拿到：**SMB1 关卡格式的完整说明**（对象格式、压缩方式、关卡数据在 ROM 的位置）+ 全代码反汇编工程
- 可用性：**格式文档可用**（可用来解析 ROM 关卡数据）；**但都需要 ROM 本体**，仓库里只有文档与反汇编源码，不含 ROM 数据
- 结论：不能直接得到 1-1 的实体坐标表

### 第 2 轮（中文，隐藏元素位置）
- 关键词：`超级马里奥 1-1 隐藏 1UP 砖块 位置 金币房 水管 数据`
- 站点：百度知道、百度文库、今日头条、B站、百度贴吧
- 拿到：**文字描述**（"1-1 第一个要跳的悬崖左边顶上有个 1up 蘑菇，在左边的水管进去有金币"）
- 可用性：❌ **不可用**。它是**文字描述，不是坐标**；按描述硬填坐标 = 编造（skill §0.5 明文禁止）
- 结论：只能当"有没有这个东西"的旁证，不能当数据

### 第 3 轮（英文，原版关卡全图 / 图集）
- 关键词：`Super Mario Bros World 1-1 full level map rip spriters-resource NES tileset sprite sheet`
- 站点：The Spriters Resource、vgmaps.de、nesmaps.com
- 拿到：原版 1-1 的**完整关卡地图**（spriters-resource `asset/20592`、nesmaps 标注地图、vgmaps `m=5492`）
- 可用性：**图可用**（作视觉基线），但 `spriters-resource.com/resources/sheets/20/20592.png` **直链实测 403**（需 referer / 反爬）⇒ 第 5 轮换站再试
- 结论：视觉基线来源之一，待拿

### 第 4 轮（中文，ROM 解包路径）
- 关键词：`超级马里奥 NES ROM 关卡数据 解包 1-1 金币房 地下关 场景对照`
- 站点：博客园（FC超级玛丽研究）、知乎、贴吧、CSDN
- 拿到：`FC超级玛丽研究` 系列（关卡表示方式 / ROM 结构的中文整理）
- 可用性：⚠️ 是**研究笔记**，不是数据表；可作为 ROM 结构的读法参考
- 结论：仍需 ROM 本体

### 第 5 轮（英文，换站点类型：romhacking / 反汇编）
- 关键词：`romhacking.net Super Mario Bros level data 1-1 object table download NES disassembly level offsets`
- 站点：Romhacking.net、Data Crystal（TCRF）、6502disassembly.com、GitHub（`smbstudio/smb1base`、`Bojidarist/smb1dg`）
- 拿到：**SMB1 的反汇编 / ROM hack 基础工程**（流程是"克隆仓库 + 汇编器 → 生成 .nes" ⇒ 仓库内**含完整关卡数据源码**）
- 可用性：✅ **可用（②级载体：可执行程序里的常量与源码）**。已把线索交给 P2 分片做交叉验证
  （`SMB1 Level Format.md` 先读格式，再从关卡数据源文件取 1-1 的对象表）
- 结论：**关卡数据不必依赖 ROM 本体** —— 反汇编工程给出了等价的一手数据

### 第 6 轮（英文，换格式：原版关卡全图 PNG）
- 关键词：`Super Mario Bros World 1-1 full level map png`（承第 3 轮）
- 站点：nesmaps.com（The Spriters Resource 直链 403；vgmaps.de 被 Cloudflare 挡）
- 操作与结果：
  - `spriters-resource.com/resources/sheets/20/20592.png` → **403**（带 Referer 仍 403）
  - `nesmaps.com` 的页面 HTML 里抓到真实图片名 `SuperMarioBrosMap1-1.png` / `1-2.png` → **下载成功**
  - 另有一次路径猜测命中一张 **256×240 的 NES 原生分辨率 1-1 首屏图**（`nes-original-1-1-first-screen.png`）
- 可用性：✅ **可用**（视觉基线）。两张全图含 **1-1 的金币房**与 **1-2 的地下密室**（地图工具把子区域画在同图内）
- 结论：视觉基线到手（粉丝制图，"Map by Rick N. Bruns"，像素取自 NES 原版）
